

# 🩺 ChatGPT 2.0 – Health Symptom Checker

A simple, interactive **symptom checker** that lets you enter your symptoms and get information about possible conditions. This is **not AI-powered**—it’s a reference tool for guidance only.

---

## 🚀 Features

* Enter symptoms and get information on related conditions
* User-friendly and easy to use
* Interactive and fully rendered in the browser
* Beginner-friendly project to showcase **rendering and interactivity**

---

## ⚡ How to Use

1. Clone the repository:

```bash
git clone https://github.com/yourusername/ChatGPT2.0-SymptomChecker.git
```

2. Open `index.html` in your browser.

3. Enter your symptoms and explore the results!
